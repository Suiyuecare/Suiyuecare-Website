# 閱讀、服務決策與諮詢導覽調整

## 2026-09-08 文章閱讀版型恢復紀錄

依使用者對手機閱讀外觀的回饋，文章頁已恢復為本次閱讀改版前的版型：標題與摘要回到主圖覆蓋層、作者／日期／閱讀時間／適合對象／標籤回到正文上方，並移除本文目錄。文章正文、圖片、提醒、清單、表格、FAQ、References、CTA、SEO、固定編號與聯絡需求預填皆保留；健康主題導覽、聯絡頁與服務／query 路由修正不受影響。

目前由 `scripts/verify-article-classic-layout.mjs` 驗證上一版結構及內容／聯絡契約。下方「文章閱讀」改版敘述為回復前的歷史紀錄，不代表目前前台狀態。

## 2026-09-08 撤回紀錄

依使用者要求，已移除七個服務頁的「先找到你在意的答案」整組導覽，以及這次新增的移工培訓計畫／實績、七張照片、外部連結與附加說明。保留既有服務內容、文章／健康／聯絡 UX、服務頁段落順序，以及不增加視覺區塊的本頁連結與 query 路由修正。原圖可由 Git 歷史復原，未刪除雲端原始資料。

目前使用 `scripts/verify-service-presentation.mjs` 驗證撤回內容未出現在原始碼或 build；`scripts/verify-service-query-rendering.mjs` 繼續驗證網址參數與非同步切頁。以下為撤回前的歷史實作及驗收紀錄，不代表目前仍保留服務導覽。

## 範圍

依 UI/UX Simplify Software 的任務優先、漸進展開與手機／鍵盤驗收原則，實作使用者指定的第 3、4、5 項。這是候選版修改，不代表已合併 main 或已部署正式站。

| 項目 | 修改前 | 修改後 |
| --- | --- | --- |
| 3：文章閱讀 | 標題與摘要覆蓋主圖、資訊密度高、長文不易定位 | 標題與圖片分離、一般字重正文、弱化中繼資料、可收合且可鍵盤操作的本文目錄 |
| 4：七個服務頁 | 決策資訊散在長頁各段 | Hero 後提供適合對象、地點、費用、開始方式四個入口；費用與申請資訊移到情境照片前；直接諮詢保留在本頁 |
| 5：健康／聯絡 | 大量分類直接展開，聯絡頁需要額外尋找表單 | 七個常見需求入口與可展開的全部主題；同名分類合併但保留舊 slug；聯絡頁直接顯示電話與完整表單，承接文章需求 |

小幫手在文章、服務、健康／搜尋及聯絡頁改為頁尾保留空間，不遮住文字、導覽或表單。首頁及其他頁面不改其位置。

## 保留的契約

- 不改文章正文、圖片資產、警示、清單、表格、FAQ、Reference、編號、slug 或 SEO 路徑。
- 不改 CMS snapshot、服務費用、資格、服務區域、申請條件或後端 API。
- 服務摘要從最後呈現的原始段落擷取；CMS 或據點資料更新後只同步摘要，不替換正在填寫的表單。
- 表單保留欄位名稱、送出端點、防垃圾欄位及需求對應。失敗保留輸入，成功才清空。
- 舊分類網址繼續匹配同分類文章；搜尋結果與全部主題不因畫面收合而刪除。
- 新文章與服務導覽使用獨立模組；需要時才載入，未放寬原有資源大小限制。
